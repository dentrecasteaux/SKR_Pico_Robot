RUN

Balance run

Start, then lift the robot slowly upright: it engages within 2° of the balance point. Kicks start 8 s after it engages, one every 3 s when it is still. End balancing drops it onto a training wheel.

DRIVE

Drive while balancing

Letting go of a button (or STOP) brings it to rest and it keeps balancing.

TUNING

Controller settings

Changes apply live, even while balancing. Saved values are re-applied whenever the SKR starts.
